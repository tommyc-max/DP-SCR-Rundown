❓ 使用步驟

負責人（整理 Rundown）
  1. 去「📋 流程表」，填主題、副標題、日期、開始時間（未定都得）。
  2. 將網站連結尾加上 #fill 發俾義工（例如 https://你嘅網址/#fill），佢哋只會見到填寫表。
  3. 義工填完，會㩒「傳去 WhatsApp／電郵」，將訊息傳返俾你。
  4. 去「🧩 彙整」，將收到嘅訊息成段貼入去，㩒「加入」。
  5. 㩒「複製 AI 指令」，貼去你慣用嘅 AI 聊天工具，再將回覆貼返嚟，㩒「讀取 AI 回覆」。
  6. 用「→ ①」「→ ②」掣套用到流程表，再喺「📋 流程表」微調。
  7. 去「📤 輸出」複製；㩒「📌 儲存目前版本」；亦可以「⬇ 下載備份」。
義工
  1. 開負責人發嘅連結。
  2. 填名字同你嘅想法，唔識打字可以㩒 🎤 講出嚟。
  3. 㩒「傳去 WhatsApp」或「電郵」，將訊息傳返俾負責人。
點樣免費放上網
  1. GitHub Pages：開 GitHub 帳戶 → New repository（揀 Public）→ Add file → Upload files，上載 index.html → Settings → Pages → 揀 Deploy from a branch，Branch 揀 main → Save。等一兩分鐘就有網址。
  2. Netlify Drop：將放咗 index.html 嘅資料夾拖入 Netlify Drop 頁面，即時有網址。
  3. 以上通常都有免費方案；介面可能會更新，請以官方畫面為準。
  4. 放上網之後，義工用網址 + #fill 就可以直接開啟。
要知道
  1. 呢個版本冇共用資料庫：每個人嘅資料只存喺自己部機嘅瀏覽器，所以義工要傳訊息俾你。
  2. 換機或交接，請用「下載備份」同「載入備份」。
  3. 清除瀏覽器資料會刪走已儲存內容，建議定期備份。
